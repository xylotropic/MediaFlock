# One local editing engine and an explicit finished-export handoff

MediaFlock will use the same project model and rendering engine in Chrome and its downloadable Mac host. Sources, preparation and exports remain local, and a saved editing project survives screen navigation; using a second native timeline renderer would introduce separate cut, caption and audio timing rules to qualify. Only a finished export explicitly selected by the owner may enter the existing private content workflow, and its attachment remains separate from Final Approval.
