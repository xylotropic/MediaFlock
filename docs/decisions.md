# Decisions

1. The requested final brand is MediaFlock. Instrument Serif matches the supplied typography reference. The supplied three-wing mark, monochrome palette, animated selection, collapsible sidebar, actual EvilCharts bar component, and minimal nine-item navigation follow subsequent user instructions. Removed taglines, workspace banners and the Experiments/Activity navigation items stay removed. Experiment services and publication history remain functional.
2. The parent workspace contains unrelated editing projects. All application work is isolated in this directory with a dedicated Git repository. The public repository contains a clean application history; private deployment records and credentials are excluded.
3. Subsequent instructions requested a real personal installation. The primary workspace uses a dedicated cloud Supabase project and private loopback web/worker services on the Mac. The isolated local workflow remains available on a different port and database. No paid service, public tunnel or social publication was used for verification.
4. A modular app and a Postgres-backed queue provide the complete loop without separate microservices. Post for Me owns accepted external schedules. External references are correlation fields, not a documented exactly-once guarantee.
5. Human approval binds immutable delivery content. Drafting tokens cannot approve; a worker rechecks current authorization at dispatch. Cancellation and rescheduling remain pending until confirmed. An in-flight external request cannot be guaranteed recalled by a later switch change.
6. Provider permission scope details are not returned by the documented account response. They stay unknown. An owner may record a per-account, generation-bound, 30-day permission attestation after checking the native/provider permission screen. This is explicitly owner evidence, not fabricated provider verification. Reconnection, credential configuration changes and expiry require fresh review and approval.
7. Use the provider's fixed Project Redirect URL for both credential modes. Native OAuth interception/redirect overrides are excluded because they target token exchange rather than the completed application callback. Quickstart LinkedIn uses the organization flow even for personal profiles. One pending attempt per owner prevents shared-cookie collisions; completed callbacks return stored results without resetting grants.
8. Platform-specific settings are allowlisted. Hidden caption/media/privacy/schedule overrides and TikTok draft uploads cannot masquerade as approved publication. Instagram placement is derived from format; YouTube Shorts require square/vertical media up to three minutes. Provider/platform limits can still reject a documented payload, which remains visible as a delivery result.
9. Optional OpenAI calls use configurable models, validated structured output, bounded retries/time/output, reserved token budgets and authorized account evidence. No API call is paid for by a ChatGPT subscription. Missing credentials leave manual editing available.
10. Performance comparisons are observational. Missing metrics remain missing, lifetime snapshots are not summed, and compatible baselines retain evidence IDs and sample sizes. Proposed observations become active writing context only after explicit human acceptance.
11. Three supplied MIT writing repositories contribute attributed drafting guidance. Their automation and engagement bots are not bundled. Fonts and UI libraries retain upstream licenses; optional third-party services are not described as open source software provided by this repository.
