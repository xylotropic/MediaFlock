# Decisions

1. The final brand is MediaFlock. Instrument Serif matches the supplied typography reference. The interface uses the supplied three-wing mark, BoardUI controls and floating sidebar, animated selection, and EvilCharts bar component. It keeps nine navigation items. Removed taglines, workspace banners, and Experiments/Activity navigation items stay removed. Experiment services and publication history still work.
2. The parent workspace contains unrelated editing projects. Application work stays in this directory with a dedicated Git repository. The public repository contains the application history. It excludes private deployment records and credentials.
3. Earlier instructions requested a real personal installation. Its workspace uses dedicated cloud Supabase and private loopback web and worker services on the Mac. The isolated local workflow uses a different port and database. Baseline verification used no paid service, public tunnel, or social publication.
4. A modular app and a Postgres queue provide the workflow without separate microservices. Post for Me owns accepted external schedules. External references help match requests and results. They do not provide a documented exactly-once guarantee.
5. Human approval binds immutable delivery content. Drafting tokens cannot approve posts. The worker checks current authorization before dispatch. Cancellation and rescheduling stay pending until confirmed. A later switch change cannot guarantee recall of an external request already in progress.
6. The documented provider account response does not return permission scopes. They stay unknown. After checking the native or provider permission screen, an owner can record an account permission review. The review binds the current connection version and expires after 30 days. It records owner evidence without claiming provider verification. Reconnection, changed credentials, and expiry require fresh review and approval.
7. Both credential modes use the provider's fixed Project Redirect URL. MediaFlock does not intercept native OAuth responses or override token-exchange redirects. Quickstart LinkedIn uses the organization flow even for personal profiles. One pending attempt per owner prevents shared-cookie conflicts. Completed callbacks return saved results without resetting grants.
8. Platform settings use an explicit allowlist. Hidden caption, media, privacy, or schedule overrides cannot replace approved content. TikTok draft uploads do not count as approved publication. Format determines Instagram placement. YouTube Shorts require square or vertical media no longer than three minutes. Provider limits can still reject a documented request, and MediaFlock retains the delivery result.
9. Live AI drafting uses the documented ChatGPT subscription OAuth flow in the trusted local Mac web process. It never falls back to API keys, a worker, an agent token, or the hosted website. The installed owner is bound offline to a verified user, workspace, Supabase project, and stable host ID. PKCE/state/nonce, verified OIDC identity, retained issued clients, atomic rotating refreshes, and encrypted local storage protect separate account registrations. Completion and evidence validation are required. Local token estimates and stream limits are admission/abort controls, not provider hard caps. Unknown usage stays reserved. ElevenLabs currently opens the signed-in website; no API access, paid call, top-up, or account connection is enabled.
10. Performance comparisons are observational. Missing metrics stay missing. The application does not add lifetime snapshots together. Compatible baselines retain evidence IDs and sample sizes. Proposed findings become active writing context only after human acceptance.
11. Three supplied MIT writing repositories contribute attributed drafting guidance. The application does not bundle their automation or engagement bots. Fonts and UI libraries retain upstream licenses. Third-party service access is separate from the open source application.
12. The public web app has a landing page at `/`, account pages, and the workspace at `/app`. Vercel can host the web app and API. The existing Mac worker retains media processing, publication, and analytics. It must stay logged in and awake. A request-bound function or daily Hobby cron does not replace it.
13. Registration starts closed. An admitted Auth user receives one private workspace. Server checks and transaction locks control identity, membership, and allocation limits. Email delivery readiness has its own flag. The existing project has no custom Auth SMTP at this preparation stage. The public signup and recovery method remains pending. A separate recovery-code feature is disabled by default and does not change Supabase confirmation policy or prove email ownership. These flags and instructions do not claim verified email delivery or a completed public deployment.
14. Large media transfers bypass Vercel functions through signed private Supabase Storage URLs. Server-generated paths and no-overwrite grants protect originals. The worker verifies bytes, hashes, and media details in a container, then creates and verifies a separate immutable original. A retry cannot replace an existing final copy. Originals, pending uploads, quarantine, and derivatives share workspace quotas. A separate server-wide storage allowance and transaction lock prevent parallel workspaces from exceeding the configured project allowance. The live default is 1 GiB. Authorized downloads use a 307 redirect to a 60-second signed URL. Provider uploads still verify checksums.
15. The Vercel web app uses a small Postgres pool and Supabase transaction pooling. The Mac worker can keep session pooling. Inline CA PEM avoids a missing certificate file on Vercel. TLS certificate checks remain enabled. Both runtimes share the existing credential vault key. Public workspaces supply their own provider keys instead of inheriting server-wide credentials.
16. Public deployment instructions describe readiness and required checks. The completion record separates earlier private-production evidence, new local coverage, and pending public-production checks. The public repository includes source and instructions without private credentials or deployment records.

17. Public media is untrusted. Live ffprobe and FFmpeg run in a dedicated, unprivileged Docker container with no network, read-only root and input files, bounded memory/CPU/processes, and bounded writable tmpfs. Official Debian packages and a pinned base digest provide the runtime; deployment records the exact installed image ID. The app refuses host fallback or runtime image pulls. Host FFmpeg remains available only for isolated demo fixtures.
18. This Colima daemon cannot copy files out of container tmpfs through `docker cp`, as verified locally. A fixed trusted helper stops decoder descendants, rejects symlink or oversized outputs, and streams only the exact named output through a bounded pipe. No writable host output directory is mounted. Cleanup removes the job container and recovers old app-owned orphans while the worker remains idle.
